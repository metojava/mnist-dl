9 · Optimizers — Math, Intuition & When to Use Each

Interface ml/optimizer/Optimizer.java:1 — step(List<Layer> layers, double lr). DenseLayer has parallel weightsGradient handling; other layers delegate via layer.update(lr). All optimizers persist via ModelSerializer.saveOptimizer/loadOptimizer.

TL;DR: Start with Adam(0.001). For transformers or heavy weight-decay use AdamW. For final CNN polish use SGD+momentum + cosine decay. Use the chart below to pick.

Schematic — not measured: Adam converges fastest; AdaGrad stalls late (accumulated cache grows); SGD needs more epochs but ends sharp.

Unified notation

gt = gradient at step t  ·  θt = parameters  ·  η = learning rate  ·  ⊙ element-wise
All updates are per-parameter; DenseLayer shards them across ThreadPoolManager.compute().

1 · SGD — Stochastic Gradient Descent ml/optimizer/SGD.java:1

Vanilla: θt+1 = θt − η · gt
+ Momentum (μ): vt+1 = μ·vt + η·gt ;   θt+1 = θt − vt+1
μ = 0.9 typical. Velocity smooths ravines; needs LR schedule. 
SGD sgd  = new SGD(0.01);           // vanilla
SGD mom  = new SGD(0.01, 0.9);       // + momentum
// per Dense param:
 // v = μ*v + lr*g
 // W -= v   (or W -= lr*g if μ==0)

Memory O(1) (or O(params) with momentum). Cheapest per step.

2 · Adam — Adaptive Moments ml/optimizer/Adam.java:1

mt = β1·mt-1 + (1−β1)·gt   (1st moment)
vt = β2·vt-1 + (1−β2)·gt2   (2nd moment)
m̂t = mt / (1−β1t) ,   v̂t = vt / (1−β2t)   (bias correction)
θt+1 = θt − η · m̂t / (√v̂t + ε)
Default β1=0.9, β2=0.999, ε=1e-8 — Kingma & Ba 2015. 
Adam adam = new Adam(0.001);
Adam full = new Adam(0.001, 0.9, 0.999, 1e-8);
// t++ ; bc1=1-β1^t ; bc2=1-β2^t ;
// m = β1*m + (1-β1)*g ; v = β2*v + (1-β2)*g²
// W -= lr * (m/bc1) / (sqrt(v/bc2)+eps)
Adam adapts per-param LR via v; bias correction fixes early steps. Best default for MNIST/Fashion, Tabular, and prototype LLMs.

3 · AdamW — Decoupled Weight Decay ml/optimizer/AdamW.java:1

Same as Adam, but weight decay not in gradient:
θt+1 = θt − η·[ m̂t/(√v̂t+ε) + λ·θt ]
λ = weightDecay (e.g., 0.01). Loshchilov & Hutter 2019 — fixes Adam+L2 coupling. 
AdamW aw = new AdamW(0.001, 0.01); // lr, wd
AdamW aw2= new AdamW(0.001, 0.9, 0.999, 1e-8, 0.01);
// inside step: W -= lr*( m̂/√v̂ + wd*W )   // W decay added after Adam term
// bias uses pure Adam (no decay)
Use for Transformers / LLMs / NLP — this library’s TransformerBlock + projects.nlp.* converge cleaner with AdamW.

4 · RMSProp ml/optimizer/RMSProp.java:1

cachet = ρ·cachet-1 + (1−ρ)·gt2
θt+1 = θt − η·gt / (√cachet + ε)
ρ=0.9, ε=1e-8 — Hinton 2012. Leaky avg of squared grad. 
RMSProp rms = new RMSProp(0.001); // ρ=0.9
RMSProp rms2= new RMSProp(0.001, 0.9, 1e-8);
// cache = ρ*cache + (1-ρ)*g² ; W -= lr*g/(√cache+eps)

Good for non-stationary RNNs where Adam’s momentum may lag. Needs careful ρ tuning.

5 · AdaGrad ml/optimizer/AdaGrad.java:1

cachet = cachet-1 + gt2   (monotonic sum)
θt+1 = θt − η·gt / (√cachet + ε)
Duchi et al 2011. No decay — LR effectively shrinks forever. 
AdaGrad ada = new AdaGrad(0.01);
AdaGrad ada2= new AdaGrad(0.01, 1e-8);
// cache += g² ; W -= lr*g/(√cache+eps)
Best for sparse BoW (e.g., projects/nlp/SentimentAnalyzer vocab-size large, many zeros). For dense CNNs prefer Adam. LR decays aggressively — often needs larger initial η (0.01 vs 0.001).

Patterns — How to choose & tune

TaskRecommendedLRWhy
MLP 784→256→10 (MNIST)Adam0.001Fast, no schedule needed
CNN 3→16→32 (CIFAR-100)SGD+μ 0.9 + cosine0.01→0Better final generalization if you can schedule
Transformer / LLMAdamW wd 0.010.001 + warmupCosineDecoupled decay stabilizes attention
RNN / LSTM seqRMSProp or Adam0.001Handles varying grad scales per timestep
Sparse BoW (vocab 5k)AdaGrad0.01Rare words get larger effective LR
Imbalanced (FocalLoss)Adam 0.0030.003Adaptive helps rare-class gradients
// Head-to-head (from examples/OptimizerBenchmark.java)
Optimizer[] opts = { new SGD(0.01), new SGD(0.01,0.9),
  new Adam(0.001), new AdamW(0.001,0.01),
  new RMSProp(0.001), new AdaGrad(0.01) };
for(Optimizer o: opts){
  NeuralNetwork net = freshNet(); // 20-64-32-5 + Softmax
  new Trainer(net, new CrossEntropyLoss(), o).fit(trainX,trainY,20,64);
  System.out.println(o.getClass().getSimpleName()+" acc "+ eval(net,testX,testY));
}
// Save/restore to resume exactly
ModelSerializer.saveOptimizer(adam, "adam.bin");
Optimizer resumed = ModelSerializer.loadOptimizer("adam.bin");
Pattern: AdamW + warmupCosine(η=0.001, maxEpochs=100, warmup=5) is the modern default for anything with TransformerBlock. For pure MLPs, plain Adam(0.001) without schedule is fine.
