10 · Activation Functions — The Non-Linearities

All extend ActivationLayer · Stateless (except PReLU) · inputSize/outputSize = -1.

ActivationFormulaDerivativeBest for
ReLUmax(0,x)1 if x>0 else 0Default for hidden layers
LeakyReLU(α=0.01)x if x>0 else αx1 or αFixes dying ReLU
ELU(α=1)x if x>0 else α(eˣ-1)1 or f+αSmooth negative regime
SELUλ·ELUλ scaledSelf-normalizing nets
GELUx·Φ(x) ≈ 0.5x(1+tanh(...))approxTransformers (BERT/GPT)
Swishx·σ(x)σ+xσ(1-σ)Modern CNNs
Mishx·tanh(softplus(x))complexSOTA vision (YOLOv4)
HardSwishx·ReLU6(x+3)/6piecewiseMobileNetV3 / edge
Sigmoid1/(1+e⁻ˣ)σ(1-σ)Binary output, gates
Tanhtanh(x)1-tanh²RNN hidden, zero-centered
Softmaxeˣⁱ/ΣeˣʲJacobianMulti-class output
Softplusln(1+eˣ)σ(x)Smooth ReLU
LogSigmoid-softplus(-x)1-σStable BCE with logits
PReLU(α learn?)x if x>0 else αx1 or αLearnable leaky
// Every activation is a Layer — drop-in anywhere
NeuralNetwork net = new NeuralNetwork()
  .add(new DenseLayer(784, 256))
  .add(new ReLU())                 // or new LeakyReLU(0.01)
  .add(new DenseLayer(256, 128))
  .add(new GELU())                 // transformer-style
  .add(new DenseLayer(128, 64))
  .add(new Mish())                 // modern vision
  .add(new DenseLayer(64, 10))
  .add(new Softmax());             // always last for classification

// Individual activations (also usable standalone)
ReLU relu = new ReLU();
Tensor out = relu.forward(someTensor, false);
Tensor grad = relu.backward(upstreamGrad);

// Parametric variants
LeakyReLU lrelu = new LeakyReLU(0.1);
ELU elu = new ELU(1.0);
PReLU prelu = new PReLU(0.25);
Softmax sm = new Softmax(); // row-wise softmax inside

// Quick reference — instantiate all 14
Layer[] all = {
  new ReLU(), new LeakyReLU(), new ELU(), new Selu(),
  new GELU(), new Swish(), new Mish(), new HardSwish(),
  new Sigmoid(), new Tanh(), new Softmax(), new Softplus(),
  new LogSigmoid(), new PReLU()
};
Rule of thumb: ReLU for MLP/CNN hidden · GELU/Swish/Mish for deep/transformer · Sigmoid for binary · Softmax for multi-class · Tanh for RNN gates.
