20 · LLMs — Build a Mini-GPT with mnist-dl

Library has all primitives for a decoder-only LLM: Embedding + TransformerBlock stack + LayerNorm + Dense(V) + CrossEntropy. This page maps LLM concepts to runnable code in this codebase.

What is an LLM? (in one paragraph)

An LLM is a next-token predictor trained on massive text: P(next | previous tokens) via CrossEntropy. At inference it generates autoregressively. Under the hood it is just Transformer decoder blocks with causal attention, trained with AdamW + warmupCosine + gradient clipping.

Training objective: ℒ = − Σt log Pθ(wt | w<t) (CrossEntropy)
Attention (causal): softmax( QKT/√d + M )·V,   Mij = −∞ if j>i else 0
Perplexity = exp(ℒ) — lower is better (random ≈ V)

Minimal LLM in 30 lines — using only mnist-dl

// === Mini-GPT: vocab 2000, d=128, 4 blocks, context 32 ===
int V=2000, d=128, heads=4, ff=512, ctx=32, N=4;
Embedding tokEmb = new Embedding(V, d);
// optional learned positional embedding (library Embedding)
Embedding posEmb = new Embedding(ctx, d);

NeuralNetwork gpt = new NeuralNetwork();
// We wrap embedding inside a custom pre-processing step:
// input ids shape [batch, ctx] -> flatten -> we use Dense as projection starter
// For teaching: feed already-embedded Tensor [batch, ctx*d]
for(int i=0;i<N;i++) gpt.add(new TransformerBlock(d, heads, ff));
gpt.add(new LayerNorm(d));
gpt.add(new DenseLayer(d, V)).add(new Softmax()); // language head

// Training loop — teacher forcing, causal without explicit mask (small ctx → full attention is ok for demo)
CrossEntropyLoss ce = new CrossEntropyLoss();
AdamW opt = new AdamW(0.001, 0.01);
GradientClipper clip = new GradientClipper(1.0);
LRScheduler sched = LRScheduler.warmupCosine(0.001, 100, 5);
for(int epoch=0; epoch<50; epoch++){
  for(Batch b: loader.iterate(ids, nextIds)){ // ids [batch, ctx]
    // 1) embed: look up tokEmb + posEmb, flatten to [batch, ctx*d] then project via Dense? 
    //    Simpler: use SentimentAnalyzer's bow idea for demo, or pre-embed before forward
    Tensor x = embedBatch(b.images(), tokEmb, posEmb); // [batch, ctx*d] helper you write
    Tensor logits = gpt.forward(x, true);   // [batch, V]
    double loss = ce.forward(logits, b.labels());
    Tensor grad = ce.backward(logits, b.labels());
    gpt.backward(grad); clip.clip(gpt.getLayers()); opt.step(gpt.getLayers(), sched.step(epoch));
  }
}
// Generation
Tensor ctxIds = seedIds; // [1, ctx]
for(int t=0; t<100; t++){
  Tensor emb = embedBatch(ctxIds, tokEmb, posEmb);
  Tensor probs = gpt.forward(emb, false);
  int next = sampleTopK(probs, 40, 0.9); // temperature/top-p you implement
  ctxIds = slide(ctxIds, next); // drop oldest, append next
}
Helper embedBatch is ~10 lines: for each token id, copy tokEmb.weights().row(id) + posEmb.row(pos). This library has no automatic token+position sum — you write it, which is the educational point.

Patterns you must implement (5)

  1. Tokenization: reuse Vocab (word-level) or build char vocab (60 chars) for tiny LLM; real LLM uses BPE — out of scope, word-level is fine for 2k vocab.
  2. Positional: learned Embedding(ctx,d) positions 0..ctx-1; sum with token embedding.
  3. Causal data: from corpus build pairs (prefix ctx-1 → next token) by sliding window; library’s DataLoader shuffles them.
  4. Masking: for strict decoder add −1e9 to future QK entries before softmax; with small ctx and full attention the model still learns causality via data order (educational shortcut).
  5. Sampling: temperature T: logits/=T before softmax; top-k/top-p truncation — implement 20 lines on top of Tensor.

Limitations of this library for real LLMs

  • CPU-only, double precision: 100M params → ~800 MB + grads — fits but slow; real LLMs use mixed-precision GPU.
  • No KV-cache, no FlashAttention: generation recomputes full attention each step (educational, not production).
  • No BPE tokenizer: word/char level only; vocab 2–5k max before Dense(V) dominates.
  • Context 32–64: self-attention is O(ctx²·d); keep ctx small (library has no sparsity).
Even with those limits, a 2–4 block, d=128, V=2000, ctx=32 model trains in minutes on CPU and already feels like a LLM on a tiny corpus (TextCorpus or your own .txt). That is the educational win.
