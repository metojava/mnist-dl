Part I — Foundations

1 · Philosophy & Architecture

What mnist-dl is, why it exists, and how it is organized.

Pure JavaNo Python, no JNI, no native libs. Java 17, Maven, JFreeChart for plotting.
Parallel by defaultTensor ops, matmul, reductions & DataLoader use ExecutorService + CompletableFuture.
Batteries included15 layers, 14 activations, 9 losses, 5 optimizers, 6 app domains with runnable projects.*.

Mental model

The library follows the classic deep learning stack: Tensor → Layer → NeuralNetwork → Loss + Optimizer + Trainer → Evaluator. Everything is composed via the Layer interface. Data flows as Tensor(rows=batch, cols=features) with row-major double arrays.

Tensor (batch × features) → [Dense → Activation → Dropout → ... → Softmax] → Loss → Optimizer.step() ↻ Trainer.fit()

2 · Tensor — The Foundation

File: ml/core/Tensor.java · Thread-safe, parallel, row-major double[] of shape [rows, cols].

Why a custom Tensor?

Java has no native ND-array. Tensor gives the whole library a single, cache-friendly, parallelized primitive without pulling in ND4J or PyTorch JNI.

Construction

Tensor a = new Tensor(32, 784);                 // zeros
Tensor b = Tensor.ones(4, 4);
Tensor c = Tensor.filled(2, 3, 0.5);
Tensor r = Tensor.random(8, 128);               // Uniform [0,1)
Tensor n = Tensor.randomNormal(8, 128);         // N(0,1)
Tensor x = Tensor.xavier(256, 128);             // Xavier/Glorot (scaled normal)
Tensor h = Tensor.he(256, 128);                 // He (good for ReLU)
Tensor t = new Tensor(new double[][]{{1,2},{3,4}});
Tensor f = Tensor.fromFlat(flatArray, 10, 784); // reshape

int[] shape = t.shape(); // [rows, cols]
double v = t.get(0, 3);
t.set(0, 3, 0.42);
double[] row = t.row(1);
Tensor slice = t.sliceRows(0, 64); // view copy of first 64 rows

Parallel execution model

Thresholds: element-wise PARALLEL_THRESHOLD=50_000, matmul MATMUL_PARALLEL_OPS=2_000_000. Above that, operations shard across ThreadPoolManager.compute() with CompletableFuture.

// Matmul is sharded by output rows
Tensor out = Tensor.matmul(a, b); // a[mxk] * b[kxn] = [mxn]
Tensor tr  = a.transpose();
Tensor sum = a.add(b);            // element-wise (also subtract/multiply/divide)
a.addInPlace(b);                  // in-place variant
Tensor scaled = a.multiply(0.5);
a.multiplyInPlace(0.5);

double s = a.sum();   // parallel reduction
double m = a.mean();
double mx = a.max(); double mn = a.min();
int best = a.argmaxRow(0);
int[] preds = a.argmaxAll();
Tensor rowSums = a.sumRows(); // [rows,1]
Tensor colSums = a.sumCols(); // [1,cols]
Tensor y = a.apply(x -> Math.max(0, x)); // parallel map
a.applyInPlace(Math::tanh);
Tensor clipped = a.clip(-1, 1);
Tensor copy = a.copy();
double[][] arr = a.toArray();
Shape discipline: The library uses 2-D tensors only. Images are flattened (e.g., 28×28 → 784), sequences are flattened as seqLen * features per row. Conv2D reconstructs H = sqrt(cols / channels) internally.

3 · The Layer Interface

File: ml/layer/Layer.java — every composable block implements this.

public interface Layer {
    Tensor forward(Tensor input, boolean training);
    Tensor backward(Tensor gradient);
    void   update(double learningRate);
    int    inputSize();
    int    outputSize();
    int    parameterCount();
    default Tensor forward(Tensor input){ return forward(input,false); }
}
  • forward(input, training) — training=true enables Dropout/BatchNorm training behaviour.
  • backward(gradient) — returns dL/dInput; stores dL/dW internally for update.
  • update(lr) — SGD step (optimizers call this or handle Dense specially).
  • inputSize/outputSize — return -1 for shape-agnostic layers (activations, pooling).

Base for activations: ActivationLayer caches lastInput/lastOutput and delegates to computeForward.

public abstract class ActivationLayer implements Layer {
    protected Tensor lastInput, lastOutput;
    public Tensor forward(Tensor input, boolean t){
        this.lastInput=input; this.lastOutput=computeForward(input); return lastOutput;
    }
    protected abstract Tensor computeForward(Tensor input);
    public int inputSize(){return -1;} public int outputSize(){return -1;}
    public int parameterCount(){return 0;} public void update(double lr){}
}
