Evaluation

Measuring how well the trained network performs.

Why do we need evaluation?

A model can perform well on training data while performing poorly on new data.

Therefore we evaluate it using a separate test dataset.

Training versus testing


Training data
     ↓
Used to change weights
     ↓
Neural network
     ↓
Test data
     ↓
Measure performance

The test data should not be used to update the model parameters.

Accuracy

Accuracy measures the percentage of predictions that are correct.

Accuracy = correct predictions / total predictions

For example, if the network correctly classifies 9,700 out of 10,000 images: 


accuracy = 9700 / 10000
         = 0.97
         = 97%

Our Evaluator

Tensor predictions =
    network.forward(images);

double loss =
    lossFunction.forward(
        predictions,
        labels
    );

int correct = 0;

for (int i = 0;
     i < predictions.rows();
     i++) {

    int prediction =
        predictions.argmaxRow(i);

    if (prediction == labels[i]) {
        correct++;
    }
}

EvaluationResult

public class EvaluationResult {

    private final double loss;
    private final double accuracy;
    private final int correct;
    private final int total;

}

Keeping these values together makes it easy for applications using the library to inspect the result.

Example result


Loss: 0.0821
Accuracy: 97.43%

Accuracy isn't everything

Accuracy is useful for MNIST, but more advanced classification problems often need additional metrics.

  • Precision
  • Recall
  • F1 score
  • Confusion matrix
  • Per-class accuracy
