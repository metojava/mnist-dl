Backpropagation

The algorithm that tells the network how its parameters should change.

The central problem

We have a network with thousands or millions of parameters. How do we know which parameters should increase or decrease?

Backpropagation solves this problem by calculating gradients.

What is a gradient?

A gradient tells us how much a value changes when a parameter changes.

For a parameter w:

∂L / ∂w

This means: "How does the loss change when this weight changes?"

The chain rule

Neural networks are compositions of functions. The chain rule lets us calculate derivatives through those compositions. 


x → f(x) → g(f(x)) → loss

The derivative becomes:

dL/dx = dL/dg × dg/df × df/dx

Backward direction

Forward propagation moves information from input to output. Backpropagation moves gradients from output back toward input. 


FORWARD

Input → Dense → ReLU → Dense → ReLU → Dense → Softmax
                                               ↓
                                              Loss


BACKWARD

Input ← Dense ← ReLU ← Dense ← ReLU ← Dense ← Gradient

Dense layer gradients

For: 


Z = XW + b

the important derivatives are: 


dW = Xᵀ dZ

db = Σ dZ

dX = dZ Wᵀ

Our Java code

weightGradients =

biasGradients =
    gradient.sumRows();

return gradient
    .matmul(weights.transpose());

The first expression calculates the weight gradients. The second calculates bias gradients. The third sends the gradient to the previous layer.

Backpropagation through the network

public Tensor backward(Tensor gradient) {

    Tensor result = gradient;

    for (int i = layers.size() - 1; i >= 0; i--) {
        result =
            layers.get(i).backward(result);
    }

    return result;
}

Notice that the layers are traversed in reverse order.

Key idea: Backpropagation doesn't directly change the weights. It calculates the gradients. The optimizer uses those gradients to change the weights.
