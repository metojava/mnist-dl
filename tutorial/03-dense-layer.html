03 / LAYERS

Dense Layers

How fully connected layers transform data.

What is a dense layer?

A dense layer is also called a fully connected layer. Every neuron in the layer receives information from every value in the previous layer.

The mathematical equation

A complete dense layer can be written as:

Z = XW + b

where:

  • X = input matrix
  • W = weight matrix
  • b = bias vector
  • Z = output before activation

Example

Suppose our input has 3 features and our layer contains 2 neurons. 


X = [ x₁ x₂ x₃ ]

W = [ w₁₁ w₁₂
      w₂₁ w₂₂
      w₃₁ w₃₂ ]

b = [ b₁ b₂ ]

The resulting output contains two values: 


z₁ = x₁w₁₁ + x₂w₂₁ + x₃w₃₁ + b₁

z₂ = x₁w₁₂ + x₂w₂₂ + x₃w₃₂ + b₂

Our Java implementation

public Tensor forward(Tensor input) {

    this.input = input;

    return input
        .matmul(weights)
        .add(broadcastBias(input.rows()));
}

The matrix multiplication performs all neuron calculations simultaneously.

Weight initialization

We initialize weights with small random values. 

double stddev =
    Math.sqrt(2.0 / inputSize);

weights.set(
    i,
    j,
    random.nextGaussian() * stddev
);

Starting all weights at zero would be problematic because neurons would behave identically and receive identical gradients.

Backpropagation through a dense layer

During training we need three important gradients. 


dW = Xᵀ dZ

db = Σ dZ

dX = dZ Wᵀ

These equations tell us how the loss changes with respect to the weights, biases and input.

Updating the parameters

After calculating the gradients: 


W = W - learningRate × dW

b = b - learningRate × db

This is the fundamental learning operation performed by our library.

Key idea: A dense layer is essentially matrix multiplication plus a bias. Its ability to learn comes from adjusting the matrix of weights.
