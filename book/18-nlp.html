18 · NLP — From BoW to Language Models

Library supports full NLP pipeline: projects/common/Vocab.java:1 + TextCorpus.java:1 → ml/layer/Embedding.java:1 → RNN/LSTM/GRU or TransformerBlock → Dense+Softmax + CrossEntropy. All 6 NLP projects are runnable offline.

Bag-of-Words: bowi = count(wordi) / |doc|  or one-hot sum
Embedding: e = Wemb[tokenId] ∈ ℝd   lookup, not matmul
Sequence likelihood: P(w1..T) = ∏t P(wt | w<t)

BoW example — SentimentAnalyzer projects/nlp/SentimentAnalyzer.java:1

List<String> texts = List.of(TextCorpus.POSITIVE, TextCorpus.NEGATIVE);
Vocab vocab = new Vocab(texts); // builds word -> id
double[][] bow = Vocab.bowMatrix(texts, vocab); // [N, V] counts
Tensor x = Tensor.fromFlat(flatten(bow), N, vocab.size);
Proj.shuffle(x, labels, new Random(42));
NeuralNetwork net = new NeuralNetwork()
  .add(new DenseLayer(vocab.size,64)).add(new ReLU()).add(new Dropout(0.3))
  .add(new DenseLayer(64,2)).add(new Softmax());
new Trainer(net, new CrossEntropyLoss(), new Adam(0.005))
  .withWeightDecay(new WeightDecay(0,1e-3)).fit(trainX,trainY,40,16);
// Demo: vocab.bow("wonderful brilliant") -> net.forward -> POS 92%

Embedding + LSTM — NextWordPredictor projects/nlp/NextWordPredictor.java:1

Input: ids [wt-k..wt-1] → Embedding(V,d) → sequence [k·d]
LSTM(d→h) → Dense(h→V) → Softmax → CE over next word
Loss: −log P(wt | context) ; perplexity = exp(loss) 
Embedding emb = new Embedding(5000, 128);
LSTMLayer lstm = new LSTMLayer(128, 128);
NeuralNetwork lm = new NeuralNetwork()
  .add(new Embedding(5000,128))
  .add(new LSTMLayer(128,128))
  .add(new DenseLayer(128,5000)).add(new Softmax());
// Training: teacher forcing — feed true prefix, predict next token

Char-level generation — CharLstmGenerator projects/nlp/CharLstmGenerator.java:1

// Alphabet size ~ 60 (a-z + punct)
// net = Embedding(60,32) -> LSTM 64 -> Dense 60 Softmax
// Generation loop (autoregressive):
Tensor cur = seedIds; // e.g., "hello "
for(int t=0;t<100;t++){
  Tensor logits = net.forward(cur,false);
  int next = sample(logits, temperature=0.8); // top-k / temp
  cur = append(cur, next);
}
Sampling controls: temperature →0 greedy, →1 stochastic, top-k / top-p truncation after softmax. Library exposes raw logits — add sampling yourself (see CharLstmGenerator).
