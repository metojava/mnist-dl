5 · Normalization: BatchNorm & LayerNorm

BatchNorm ml/layer/BatchNorm.java

Normalizes across batch: y = γ·(x-μ)/√(σ²+ε) + β. Tracks runningMean/runningVar for inference.

BatchNorm bn = new BatchNorm(128); // featureSize
NeuralNetwork net = new NeuralNetwork()
  .add(new DenseLayer(784,128))
  .add(new BatchNorm(128))
  .add(new ReLU())
  .add(new DenseLayer(128,10))
  .add(new Softmax());

Tensor trainOut = net.forward(batch, true);  // uses batch stats
Tensor testOut  = net.forward(batch, false); // uses running stats

// Trainable params
Tensor gamma = bn.gamma(); // [1,128]
Tensor beta  = bn.beta();

LayerNorm ml/layer/LayerNorm.java

Normalizes across features per sample (Transformer staple). No running stats; always uses per-row mean/var.

LayerNorm ln = new LayerNorm(512);
TransformerBlock block = new TransformerBlock(512, 8, 2048);

NeuralNetwork seq = new NeuralNetwork()
  .add(new DenseLayer(128,512))
  .add(new LayerNorm(512))
  .add(new TransformerBlock(512, 8, 2048))
  .add(new DenseLayer(512, 10));

// Inside TransformerBlock (preNorm=true by default):
// x → LayerNorm → MultiHeadAttention → Dropout → residual
//   → LayerNorm → FFN(ReLU) → Dropout → residual
LayerNormalizes overParamsBest for
BatchNormBatch dim2×features (γ,β)CNNs, MLPs with batch > 16
LayerNormFeature dim per sample2×features (γ,β)Transformers, RNNs, batch=1

6 · Pooling: MaxPool & AvgPool

Files: ml/layer/MaxPool.java, AvgPool.java · Parameter-free spatial downsampling.

MaxPool

MaxPool pool2 = new MaxPool(2);       // 2×2, stride 2
MaxPool pool3 = new MaxPool(3, 1);    // 3×3, stride 1
NeuralNetwork net = new NeuralNetwork()
  .add(new Conv2D(1,16,3))
  .add(new ReLU())
  .add(new MaxPool(2))  // 28×28 → 14×14
  .add(new Conv2D(16,32,3))
  .add(new MaxPool(2)); // 14×14 → 7×7 (approx, depends on valid conv)

Keeps strongest activation per window — best for feature selection, translation invariance.

AvgPool

AvgPool avg = new AvgPool(2);
NeuralNetwork net2 = new NeuralNetwork()
  .add(new Conv2D(1,16,3))
  .add(new AvgPool(2))
  .add(new Flatten());
// AvgPool backward distributes gradient uniformly (1/(k*k))

Averages window — smoother, often used before global pooling / classification head.

Both infer H = sqrt(cols) (or sqrt(cols/channels)) and compute outH = (H - pool)/stride + 1. Report inputSize/outputSize = -1 so shape checks are skipped.
