Forward Propagation

How input data travels through the network.

What is forward propagation?

Forward propagation is the process of taking an input and passing it through every layer until we obtain a prediction. 


Input
  ↓
Dense
  ↓
ReLU
  ↓
Dense
  ↓
ReLU
  ↓
Dense
  ↓
Softmax
  ↓
Prediction

Our network's forward method

public Tensor forward(Tensor input) {

    Tensor result = input;

    for (Layer layer : layers) {
        result = layer.forward(result);
    }

    return result;
}

Notice how simple this method is. Each layer knows how to process its own input.

Example with MNIST

An MNIST image has 28 × 28 pixels. We flatten it into 784 numbers. 


28 × 28 image
      ↓
784 values
      ↓
Dense(784 → 128)
      ↓
128 values
      ↓
ReLU
      ↓
Dense(128 → 64)
      ↓
64 values
      ↓
ReLU
      ↓
Dense(64 → 10)
      ↓
10 values
      ↓
Softmax
      ↓
10 probabilities

Prediction

After softmax, each output corresponds to one digit. 


index:        0      1      2      3      4
probability: .01    .02    .03    .01    .05

index:        5      6      7      8      9
probability: .02    .04    .79    .02    .01

The highest probability is class 7, so the network predicts the digit 7.

Argmax

int prediction =

Important: Forward propagation is used both during training and during prediction. Training adds the additional steps of calculating loss, gradients and updating parameters.
