04 / NONLINEARITY

Activation Functions

ReLU, Softmax and why neural networks need nonlinear functions.

Why do we need activations?

Imagine stacking several dense layers without any activation function between them.

Every layer performs a linear transformation: 


Z₁ = XW₁ + b₁

Z₂ = Z₁W₂ + b₂

Multiple linear transformations can be mathematically combined into one linear transformation.

Therefore, without nonlinear activation functions, adding more layers would not give the network much additional expressive power.

ReLU

ReLU means Rectified Linear Unit.

ReLU(x) = max(0, x)

Examples: 


ReLU(-5) = 0
ReLU(-1) = 0
ReLU( 0) = 0
ReLU( 2) = 2
ReLU( 7) = 7

Java implementation

for (int i = 0; i < input.rows(); i++) {
    for (int j = 0; j < input.cols(); j++) {

        output.set(
            i,
            j,
            Math.max(0.0, input.get(i, j))
        );
    }
}

ReLU derivative

During backpropagation we need the derivative.

ReLU'(x) = 0 if x ≤ 0
ReLU'(x) = 1 if x > 0

This allows gradients to pass through positive neurons while blocking them for negative values.

Softmax

The final layer of our classifier needs to convert its raw outputs into probabilities.

softmax(xᵢ) = eˣⁱ / Σⱼ eˣʲ

For example: 


[2.0, 1.0, 0.1]

        ↓

[0.659, 0.242, 0.099]

The probabilities add up to approximately 1.

Why subtract the maximum?

Computing exponentials can produce very large numbers. To improve numerical stability we calculate: 


exp(xᵢ - max(x))

Subtracting the same constant from every value does not change the final softmax probabilities, but it prevents unnecessarily huge exponentials.

Key idea: ReLU gives hidden layers nonlinear expressive power. Softmax turns the final outputs into class probabilities.
