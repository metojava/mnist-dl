DenseLayer — Fully Connected ml/layer/DenseLayer.java

Computes y = x·Wᵀ + b with He-initialized W[outputSize × inputSize]. Backward is parallel sharded; bias broadcasting and weight update are parallel.

DenseLayer fc1 = new DenseLayer(784, 256); // in=784, out=256
DenseLayer fc2 = new DenseLayer(256, 10);

NeuralNetwork net = new NeuralNetwork().add(fc1).add(new ReLU()).add(fc2);
Tensor out = net.forward(batch);          // [batch,10]
Tensor dInput = fc2.backward(grad);       // returns dL/dx
fc2.update(0.001);                        // SGD step

// Introspection
Tensor W = fc1.weights();   // [256,784]
Tensor b = fc1.bias();      // [1,256]
Tensor dW = fc1.weightsGradient();
System.out.println(net.totalParameters());

// Shape guard — throws LayerConfigurationException on mismatch
new NeuralNetwork().add(new DenseLayer(10,20)).add(new DenseLayer(30,5)); // ❌ throws
When to use: Tabular data, MLP heads, final classifier after Conv/Recurrent stacks. Parameter count = in×out + out.

Conv2D — 2D Convolution ml/layer/Conv2D.java

Square images assumed: H = sqrt(cols / inChannels). Supports stride, padding, multiple output channels. Kernels are Tensor[inChannels·k·k, 1] per output channel.

// Classic LeNet-style stem for 28×28 grayscale
Conv2D conv1 = new Conv2D(1, 16, 3);              // 1→16 channels, 3×3 kernel
Conv2D conv2 = new Conv2D(16, 32, 3, 1, 1, new Random(0)); // stride 1, pad 1

NeuralNetwork cnn = new NeuralNetwork()
  .add(new Conv2D(1, 16, 3))
  .add(new ReLU())
  .add(new MaxPool(2))          // 28→14
  .add(new Conv2D(16, 32, 3))
  .add(new ReLU())
  .add(new MaxPool(2))          // 14→7  (32*7*7 = 1568 features)
  .add(new Flatten())
  .add(new DenseLayer(1568, 128))
  .add(new ReLU())
  .add(new DenseLayer(128, 10))
  .add(new Softmax());

// Access kernels
Tensor k0 = conv1.kernel(0);
double[] bias = conv1.biases();
int params = conv1.parameterCount(); // outC*inC*k*k + outC

Flatten ml/layer/Flatten.java

Reshapes [batch, H·W·C] → [batch, H·W·C] (logically flattens spatial dims for Dense). No parameters, backward is identity reshape.

Flatten flat = new Flatten();
NeuralNetwork net2 = new NeuralNetwork().add(new Conv2D(1,8,3)).add(new Flatten()).add(new DenseLayer(-1,64));
// Note: Flatten reports inputSize/outputSize = -1 so NeuralNetwork skips shape check

Embedding ml/layer/Embedding.java

Lookup table [vocabSize × embeddingDim]. Input is expected to carry token ids (as doubles) — projects encode via Vocab + bag-of-words or id sequences.

Embedding emb = new Embedding(5000, 128); // vocab 5k, dim 128
Tensor ids = Tensor.fromFlat(new double[]{12, 45, 7, 0}, 1, 4);
Tensor embedded = emb.forward(ids, true); // [1, 4*128] — flattened sequence
System.out.println(emb.parameterCount()); // 5000*128
Tip: For NLP, combine Embedding → LSTMLayer → Dense → Softmax. See Projects P06–P11.
