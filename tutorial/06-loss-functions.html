Loss Functions

Measuring how wrong the neural network is.

Why do we need a loss?

The network produces predictions, but we need a numerical way to describe how good or bad those predictions are.

That number is called the loss.

Lower loss generally means the predictions are closer to the desired targets.

Cross-entropy

For classification we use cross-entropy loss.

L = -log(pᵧ)

Here pᵧ is the probability assigned to the correct class.

Example

Suppose the correct digit is 7.

If the network gives digit 7 a probability of 0.9: 


loss = -log(0.9)
     ≈ 0.105

That's a small loss.

If it gives digit 7 a probability of 0.01: 


loss = -log(0.01)
     ≈ 4.605

That's a much larger loss.

Our Java implementation

double probability =
    Math.max(
        predictions.get(i, label),
        EPSILON
    );

totalLoss -= Math.log(probability);

The small epsilon prevents taking the logarithm of zero.

Average batch loss

For a batch containing multiple examples, we average their losses:

L = (1/N) Σ Lᵢ

Averaging gives us a loss value that is independent of the particular batch size.

Loss is more than a score

The loss is also the starting point for backpropagation. 


Prediction
     ↓
   Loss
     ↓
  Gradient
     ↓
Backpropagation
     ↓
Weight updates
Key idea: The network learns by changing its parameters so that the loss becomes smaller.
