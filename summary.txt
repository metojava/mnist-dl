# Java Deep Learning Library - Project Summary
## Path: C:\Users\dell\Desktop\mnist-dl

## What It Is
Production-ready Java deep learning library with:
- Organized package structure (80+ source files)
- Parallelism via Java ExecutorService
- Proper concurrency (locks, thread pools)
- Keras-like model API: `Dense(128, relu) → Dense(10, softmax)`
- Functional API for DAG-based models (multi-input, multi-output)

## Performance
- Old code: 12-16s/epoch (3 layers, SGD, no dropout)
- New code: ~7s/epoch (2 layers), ~24s/epoch (4 layers, Adam, dropout)
- 4-layer slower due to 3.6x more FLOPs, not parallelism regression

## NEW ADDITIONS (Latest Session)

### Recurrent Layers (3 new files)
- `ml.layer.RNNLayer` - Basic recurrent layer with configurable activation (tanh/relu/sigmoid/elu)
- `ml.layer.LSTMLayer` - Long Short-Term Memory with forget/input/output gates
- `ml.layer.GRULayer` - Gated Recurrent Unit (simplified LSTM)
- All support bidirectional mode and returnSequences

### Attention/Transformer Layers (3 new files)
- `ml.layer.SelfAttention` - Scaled dot-product self-attention
- `ml.layer.MultiHeadAttention` - Multiple attention heads + projection (supports cross-attention)
- `ml.layer.TransformerBlock` - Self-attention + LayerNorm + FFN + residual connections (pre/post-norm)

### New Activations (5 new files)
- `ml.activation.Mish` - Self-regularized: x * tanh(softplus(x))
- `ml.activation.HardSwish` - Efficient mobile: x * ReLU6(x+3) / 6
- `ml.activation.PReLU` - Parametric ReLU with learnable alpha parameter
- `ml.activation.Softplus` - Smooth ReLU: log(1 + exp(x))
- `ml.activation.LogSigmoid` - Log of sigmoid: log(sigmoid(x))

### New Loss Functions (4 new files)
- `ml.loss.KLDivergenceLoss` - KL divergence for VAEs, distribution matching
- `ml.loss.FocalLoss` - Focal loss for imbalanced classification (configurable alpha/gamma)
- `ml.loss.CosineEmbeddingLoss` - Cosine similarity loss for similarity learning
- `ml.loss.CTCLoss` - Connectionist Temporal Classification for sequence-to-sequence

### New Initializers (added to Initializers.java)
- `glorotUniform()` / `glorotNormal()` - Xavier initialization (alias)
- `orthogonal()` - For RNN weight initialization
- `truncatedNormal()` - Clipped gaussian initialization
- Tensor versions: `glorotUniformTensor()`, `glorotNormalTensor()`, `orthogonalTensor()`

### Training Infrastructure (5 new files)
- `ml.training.Metrics` - Accuracy, Precision, Recall, F1, top-K accuracy, classification report
- `ml.training.Callback` - Interface with onEpochEnd, onBatchEnd, onTrainBegin, etc.
- `ml.training.ModelCheckpoint` - Save best model during training with configurable monitor
- `ml.training.ModelSummary` - Keras-style pretty-print architecture table
- `ml.training.TensorBoardLogger` - Real TensorBoard event file format (scalars + histograms)

### Data Augmentation (4 new files)
- `ml.augmentation.RandomFlip` - Horizontal/vertical/both flip with probability
- `ml.augmentation.RandomRotation` - Random angle rotation with bilinear interpolation
- `ml.augmentation.RandomCrop` - Random crop with configurable size
- `ml.augmentation.RandomZoom` - Random zoom in/out with bilinear interpolation

### Functional API (1 new file)
- `ml.network.Functional` - Build DAG-based models with multiple inputs/outputs
- Supports: `input()`, `apply()`, `concatenate()`, `add()`, `build()`
- Topological sort for correct forward/backward execution order

### Data Reading (2 new files)
- `ml.util.DataReader` - Read 10 ML file formats into Tensors
- `ml.util.LocalInputFile` - Lightweight parquet file reader without Hadoop Path API
- Supported formats: CSV, TSV, JSON, TXT, Parquet, Numpy (.npy), NumpyZip (.npz), Safetensors, ARFF, LibSVM
- Auto-detect format by file extension via `detectFormat()`
- Returns: `DataResult(Tensor features, int[] labels, String[] columnNames)`
- Methods: `read()`, `readCsv()`, `readTsv()`, `readJson()`, `readTxt()`, `readParquet()`, `readNumpy()`, `readNumpyZip()`, `readSafetensors()`, `readArff()`, `readLibSvm()`
- Helper: `printDataInfo()` for data inspection
- CSV supports: headers, custom delimiters, label column, quoted fields
- Parquet uses minimal Hadoop deps (exclusions for yarn, HDFS, mapreduce, auth, etc.)
- Numpy supports: .npy (single array) and .npz (zip of arrays), all dtypes (f2/f4/f8, i1/i2/i4/i8, u1)
- Safetensors: pure Java reader for HuggingFace format
- ARFF: Weka format support
- LibSVM: sparse feature format support

### Image Processing (1 new file)
- `ml.util.ImageReader` - Full image I/O and processing pipeline using JavaCV/OpenCV
- **Read**: any format (JPG, PNG, BMP, TIFF, WebP, etc.) via OpenCV
- **Write**: JPG (configurable quality), PNG (configurable compression), TIFF, BMP, WebP
- **Resize**: resize, resizeToTensorSize, resizeShortestSide (with interpolation: nearest, linear, cubic, lanczos)
- **Crop**: crop, centerCrop, randomCrop
- **Flip**: flipHorizontal, flipVertical, flipBoth
- **Rotate**: rotate (arbitrary angle), rotate90, rotate180, rotate270
- **Zoom**: zoom in/out with center crop
- **Color**: toGrayscale, toRGB, toBGR, toRGBA
- **Normalize**: normalize (0-1), normalizeMeanStd (ImageNet style)
- **Augmentation**: randomFlip, randomRotation, randomCrop, randomZoom
- **Tensor conversion**: toTensor (NCHW format), batchToTensor, tensorToImage, batchTensorToImages
- **Directory ops**: readDirectory, readDirectoryAsTensor, countImages
- **Filter**: gaussianBlur, sharpen, brightness, contrast, medianBlur, bilateralFilter
- **Morphology**: dilate, erode, morphOpen, morphClose
- **Edge**: cannyEdge, equalizeHistogram, threshold
