7 · Recurrence: RNN, LSTM, GRU

Sequence layers consume Tensor[batch, seqLen*inputSize] flattened. They are the workhorses for time-series and NLP.

RNNLayer ml/layer/RNNLayer.java

Elman RNN with tanh/ReLU/sigmoid/ELU. Supports bidirectional and returnSequences.

RNNLayer rnn = new RNNLayer(1, 64); // input 1-dim, hidden 64
RNNLayer birnn = new RNNLayer(8, 32, true); // bidirectional
RNNLayer seqRnn = new RNNLayer(10, 32, false, true, "relu"); // returns all timesteps

Tensor seq = new Tensor(16, 20*10); // batch 16, seqLen 20, feat 10
Tensor lastHidden = rnn.forward(seq, true);      // [16,64]
Tensor allHidden  = seqRnn.forward(seq, true);   // [16,20*32]

LSTMLayer — True BPTT ml/layer/LSTMLayer.java

Full LSTM with forget/input/output gates + cell state and true backprop-through-time. Bidirectional concatenates forward+backward hiddens. ~4× params of RNN.

// Temperature forecasting: 24h lookback → next temp
LSTMLayer lstm = new LSTMLayer(1, 64);
NeuralNetwork forecaster = new NeuralNetwork()
  .add(new LSTMLayer(1, 64))          // [batch, 24*1] → [batch,64]
  .add(new DenseLayer(64, 32))
  .add(new ReLU())
  .add(new DenseLayer(32, 1));        // regression output

// Sequence-to-sequence (returnSequences=true) — stack them!
NeuralNetwork stacked = new NeuralNetwork()
  .add(new LSTMLayer(10, 64, false, true))  // → [batch, seqLen*64]
  .add(new LSTMLayer(64, 32))                // → [batch,32]
  .add(new DenseLayer(32, 5))
  .add(new Softmax());

// Bidirectional for NLP
LSTMLayer bilstm = new LSTMLayer(128, 64, true, false);
System.out.println(lstm.parameterCount()); // 4*(in*hid + hid*hid + hid)

GRULayer ml/layer/GRULayer.java

Gated Recurrent Unit — 3 gates (update, reset, candidate), lighter than LSTM, strong on small datasets.

GRULayer gru = new GRULayer(10, 64);
GRULayer bigru = new GRULayer(10, 32, true);
NeuralNetwork net = new NeuralNetwork()
  .add(new Embedding(1000, 32))
  .add(new GRULayer(32, 64))
  .add(new DenseLayer(64, 2))
  .add(new Softmax());
