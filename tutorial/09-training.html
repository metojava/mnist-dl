09 / TRAINING

The Training Loop

Putting forward propagation, loss, backpropagation and optimization together.

The complete algorithm

  1. Select a batch.
  2. Run forward propagation.
  3. Calculate the loss.
  4. Calculate the loss gradient.
  5. Run backpropagation.
  6. Update the parameters.
  7. Repeat.

Training loop

for each epoch:

    shuffle training data

    for each batch:

        predictions =
            network.forward(batchX)

        loss =
            lossFunction.forward(
                predictions,
                batchY
            )

        gradient =
            lossFunction.backward(
                predictions,
                batchY
            )

        network.backward(gradient)

        network.update(learningRate)

Epoch

An epoch means processing the entire training dataset once.

If MNIST contains 60,000 training images, then one epoch means the network has processed all 60,000 images.

Batch size

If the batch size is 32: 


60,000 / 32 ≈ 1,875 batches

Each batch results in a parameter update.

Why shuffle?

We randomly reorder the training examples at the beginning of each epoch.

This prevents the model from repeatedly seeing the same ordering of examples.

What does learning look like?


Epoch 1/10 - loss: 0.45
Epoch 2/10 - loss: 0.23
Epoch 3/10 - loss: 0.17
Epoch 4/10 - loss: 0.13
...
Epoch 10/10 - loss: 0.06

Generally we want the training loss to decrease as training progresses.

When training goes wrong

Loss doesn't decrease

  • Learning rate may be inappropriate.
  • Gradients may be incorrect.
  • Input data may not be normalized.
  • Weight initialization may be problematic.

Loss becomes NaN

  • Numerical instability may be occurring.
  • Exponentials may overflow.
  • Learning rate may be too large.

Training is extremely slow

  • The pure Java implementation uses basic arrays.
  • Matrix operations are not optimized.
  • There is no GPU acceleration.
Key idea: Training is simply repeating the same mathematical process many times while gradually improving the parameters.
