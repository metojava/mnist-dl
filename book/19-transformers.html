19 · Transformers — Self-Attention to TransformerBlock

Files: ml/layer/SelfAttention.java:1, MultiHeadAttention.java:1, TransformerBlock.java:1. This library implements scaled dot-product attention exactly as “Attention Is All You Need”.

Scaled dot-product attention — formula

Q = X·WQT,   K = X·WKT,   V = X·WVT   ∈ ℝseq×d
Attention(Q,K,V) = softmax( Q·KT / √dk ) · V
Scaling by √dk prevents large dot-products → softmax saturation. Library does this when scaled=true.
Q = Q Input X WK=K Input XWV=V QKT/√dsoftmax →Attn·V →WO

Multi-head — why & how

Split dmodel into h heads: dk=dmodel/h
headi = Attention( Q·WQi, K·WKi, V·WVi )
MultiHead = Concat(head1..headh) · WO
Library: new MultiHeadAttention(512,8) → 8 heads × 64-d each.
O → 128 Each head attends to different pattern (syntax vs semantics). More heads = richer. 
SelfAttention sa = new SelfAttention(64); // single head
MultiHeadAttention mha = new MultiHeadAttention(512, 8); // 8 heads
MultiHeadAttention cross = new MultiHeadAttention(512, 8, true); // cross-attn
Tensor q = new Tensor(4, 10*512), kv = new Tensor(4, 12*512);
Tensor out = cross.forward(q, kv, true); // query vs encoder output

TransformerBlock — the Lego brick ml/layer/TransformerBlock.java:1

Pre-LN (default, stable):
x₁ = x + Dropout( MHA( LayerNorm(x) ) )
y = x₁ + Dropout( FFN( LayerNorm(x₁) ) ),   FFN = Dense(d→ff) ReLU Dense(ff→d) 
TransformerBlock block = new TransformerBlock(512, 8, 2048); // d=512 h=8 ff=2048
TransformerBlock cross = new TransformerBlock(512, 8, 2048, true, true, 0.1); // cross
NeuralNetwork enc = new NeuralNetwork()
  .add(new DenseLayer(64,512))
  .add(new TransformerBlock(512,8,2048))
  .add(new TransformerBlock(512,8,2048))
  .add(new LayerNorm(512))
  .add(new DenseLayer(512, 1000)).add(new Softmax());
Pattern: Stack 2–6 blocks, each ~ 4·d² params. Use LayerNorm after stack, Dropout(0.1) inside block (library does it), AdamW + warmupCosine.
