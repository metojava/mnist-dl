Section: Examples

15 - Examples - Runnable entry points

Each file in src/main/java/examples/ is a self-contained main(). Run via mvn compile exec:java -Dexec.mainClass=examples.<Name>.

FileRoleCore idea
BenchEpoch.javaBenchmark harnessWarms up JIT then times 3 epochs of MLP on Fashion-MNIST (784-256-128-64-10) with Adam+Clip+WeightDecay. Use to compare Trainer overhead.
BinaryClassificationExample.javaBinary classifierSynthetic 8-D Gaussian data where y = (x0+x1>0). MLP 8-32-16-1 with ReLU+Dropout+Sigmoid, BCE loss, Adam, 30 epochs. Shows BCE+Sigmoid pairing and ConfusionMatrix.
DiagBench.javaSingle-batch diagnosticsRuns exactly ONE forward/backward/step on 32 MNIST rows and prints every intermediate: output stats, loss, grad norms, weight L2 before/after SGD. Debug exploding/vanishing grads.
ManualBench.javaManual training loopSame 784-128-10 net but WITHOUT Trainer: iterates DataLoader manually, calls forward/loss/backward/step. Proves what Trainer abstracts.
MinimalBench.javaFixed-batch stress testReuses the SAME 128 samples for 100 steps x 5 epochs. Isolates compute from DataLoader/Shuffle overhead — pure matmul+activation speed.
MNISTClassification.javaFashion-MNIST main demoThe canonical example: loads Fashion-MNIST via MNISTLoader, builds 784-256-128-64-10 + Dropout, trains with Adam+Clip+L2 for 10 epochs, evaluates with Evaluator+ConfusionMatrix, saves chart+model.
NoDataLoaderBench.javaNo DataLoader baselineShuffles via raw perm array and builds Tensor.fromFlat manually per batch. Compares cost of not using DataLoader vs Trainer.
OptimizerBenchmark.javaAll 6 optimizers head-to-headSynthetic 5-class Gaussian mixture (20-D). Trains identical 20-64-32-5 + Softmax nets with SGD, SGD+mom, Adam, AdamW, RMSProp, AdaGrad for 20 epochs and prints accuracy/time.
RegressionExample.javaSynthetic regressionGenerates y = 2x0-1.5x1+0.5x2+3x3-0.8x4 + N(0,1) plus bias 1.5. MLP 5-32-16-1 with MSELoss + Adam + GradientClipper. Demonstrates regression head (no activation) and MSELoss.
SimpleBench.javaKeras-style 2-layerMinimal 784-128-10 + Softmax with SGD(0.1), 10 epochs, batch 128. Then manual batched evaluation loop computing accuracy. Cleanest start.
Tip: Start with SimpleBench then MNISTClassification then OptimizerBenchmark.

Common run pattern

SeedManager.setSeed(42);
Dataset ds = MNISTLoader.load("data/train-images-idx3-ubyte","data/train-labels-idx1-ubyte");
NeuralNetwork net = new NeuralNetwork().add(new DenseLayer(784,128)).add(new ReLU()).add(new DenseLayer(128,10)).add(new Softmax());
Trainer t = new Trainer(net, new CrossEntropyLoss(), new Adam(0.001));
t.fit(ds.images(), ds.labels(), 10, 128);
