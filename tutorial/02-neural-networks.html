Neural Networks

Understanding neurons, layers, weights and biases.

What is a neural network?

A neural network is a mathematical function made from multiple connected layers.

The network receives an input, transforms it through several layers, and produces an output. 


Input
  ↓
Layer 1
  ↓
Layer 2
  ↓
Layer 3
  ↓
Output

A neuron

A basic neuron calculates a weighted sum of its inputs. 


z = x₁w₁ + x₂w₂ + x₃w₃ + b

Here:

  • x = input
  • w = weight
  • b = bias
  • z = weighted result

Weights

Weights determine how strongly one input affects a neuron.

During training the network learns good values for these weights.

Bias

A bias allows a neuron to shift its activation. 


z = wx + b

Without a bias, the function is forced to pass through zero. The bias gives the network additional flexibility.

Layers

A layer contains multiple neurons.

Our MNIST network will contain: 


784 inputs
   ↓
128 neurons
   ↓
64 neurons
   ↓
10 neurons

The network in Java

NeuralNetwork network =
    new NeuralNetwork()

        .add(new DenseLayer(784, 128))
        .add(new ReLU())

        .add(new DenseLayer(128, 64))
        .add(new ReLU())

        .add(new DenseLayer(64, 10))
        .add(new Softmax());

This API makes the architecture readable from top to bottom.

What does "deep" mean?

A neural network with multiple learnable layers is commonly called a deep neural network.

The word "deep" refers primarily to the number of layers through which information passes.

Key idea: The network itself does not "know" what a handwritten digit is. It learns numerical parameters that allow it to transform pixel values into useful predictions.
