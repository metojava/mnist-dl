22 · Saving & Loading — Binary vs JSON vs SafeTensors vs ONNX (+ Optimizer)

Yes — the API saves to four distinct formats plus optimizer checkpoints. This page is the definitive reference.

Answer: Yes, covered briefly in 11 · Evaluation and expanded here. NeuralNetwork delegates to ModelSerializer (ml/network/ModelSerializer.java:18 and ml/network/NeuralNetwork.java:81) which implements binary (full), JSON (partial), Safetensors and ONNX.

One-line API — all four formats

// Binary (preferred, versioned "mnist-dl/2.0")
net.saveModel("model.bin"); // NeuralNetwork.java:83 -> ModelSerializer.saveBinary:190
NeuralNetwork n1 = NeuralNetwork.loadModel("model.bin"); // ModelSerializer.loadBinary:287

// JSON (diffable, "mnist-dl/1.0")
net.saveJson("model.json"); // ModelSerializer.saveJson:22
NeuralNetwork n2 = NeuralNetwork.loadJson("model.json"); // ModelSerializer.loadJson:90

// SafeTensors (HF compatible, F64 LE)
net.saveSafetensors("model.safetensors"); // NeuralNetwork.java:99 -> ModelSerializer.saveSafetensors
NeuralNetwork n3 = NeuralNetwork.loadSafetensors("model.safetensors");

// ONNX (JSON-based, ir_version 7)
net.saveOnnx("model.onnx"); // NeuralNetwork.java:107 -> ModelSerializer.saveOnnx
NeuralNetwork n4 = NeuralNetwork.loadOnnx("model.onnx");

// Optimizer state (binary)
ModelSerializer.saveOptimizer(new Adam(0.001), "adam.bin"); // ModelSerializer.saveOptimizer:447
Optimizer resumed = ModelSerializer.loadOptimizer("adam.bin"); // ModelSerializer.loadOptimizer:469
