Tensors and Matrices

The numerical foundation of our deep-learning library.

What is a tensor?

A tensor is simply a mathematical container for numbers. In this project we start with two-dimensional tensors, which are matrices.

A matrix can be represented as rows and columns: 


[ 1  2  3 ]
[ 4  5  6 ]

This matrix has 2 rows and 3 columns, so its shape is: 

2 × 3

Why does deep learning need matrices?

Neural networks perform huge numbers of mathematical operations. Matrix multiplication lets us perform many calculations at once.

Instead of calculating every neuron independently, we can represent an entire layer using matrix operations.

Our Tensor class

public class Tensor {

    private final int rows;
    private final int cols;
    private final double[][] data;

}

Internally our tensor is simply a Java double[][].

This isn't the fastest possible implementation, but it makes the mathematics very easy to understand.

Matrix multiplication

Suppose we have: 


A = [ 1  2 ]
    [ 3  4 ]

B = [ 5  6 ]
    [ 7  8 ]

The multiplication is: 


A × B

= [ 1×5 + 2×7    1×6 + 2×8 ]
  [ 3×5 + 4×7    3×6 + 4×8 ]

= [ 19  22 ]
  [ 43  50 ]

Our implementation

public Tensor matmul(Tensor other) {

    if (cols != other.rows) {
        throw new IllegalArgumentException(
            "Incompatible tensor shapes."
        );
    }

    Tensor result =
        new Tensor(rows, other.cols);

    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < other.cols; j++) {

            double sum = 0.0;

            for (int k = 0; k < cols; k++) {
                sum +=
                    data[i][k] *
                    other.data[k][j];
            }

            result.data[i][j] = sum;
        }
    }

    return result;
}
