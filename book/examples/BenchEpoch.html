BenchEpoch

Benchmark harness - Warms up JIT then times 3 epochs of MLP on Fashion-MNIST (784-256-128-64-10) with Adam+Clip+WeightDecay. Use to compare Trainer overhead.

ML principles realized

  • MLP for Fashion-MNIST (10 classes) with He init + ReLU + Dropout(0.2).
  • Adam + L2 + Gradient clipping: decoupling of optimizer, regularizer, and gradient norm control.
  • Benchmark discipline: one warmup epoch to trigger JIT before timing — isolates steady-state throughput.

Code walkthrough

SeedManager.setSeed(42); // deterministic He init
Dataset trainData = MNISTLoader.load(...); // 60k x 784
NeuralNetwork = 784-256 ReLU Dropout0.2 - 256-128 ReLU Dropout0.2 - 128-64 ReLU - 64-10 Softmax
Trainer = CrossEntropyLoss + Adam(0.001) + GradientClipper(5.0) + WeightDecay(L2=1e-4)
trainer.fit(...,1,256); // warmup JIT
fit(...,3,256); // timed

What to learn

How dropout/batch interplay with Trainer loop, why warmup matters for fair timing, and typical Fashion-MNIST MLP depth/width.

Full source - src/main/java/examples/BenchEpoch.java

package examples;

import ml.core.Tensor;
import ml.core.SeedManager;
import ml.network.NeuralNetwork;
import ml.training.*;
import ml.optimizer.Adam;
import ml.loss.CrossEntropyLoss;
import ml.util.MNISTLoader;

public class BenchEpoch {
    public static void main(String[] args) throws Exception {
        SeedManager.setSeed(42);
        Dataset trainData = MNISTLoader.load("data/train-images-idx3-ubyte", "data/train-labels-idx1-ubyte");

        NeuralNetwork network = new NeuralNetwork();
        network.add(new ml.layer.DenseLayer(784, 256));
        network.add(new ml.activation.ReLU());
        network.add(new ml.regularization.Dropout(0.2));
        network.add(new ml.layer.DenseLayer(256, 128));
        network.add(new ml.activation.ReLU());
        network.add(new ml.regularization.Dropout(0.2));
        network.add(new ml.layer.DenseLayer(128, 64));
        network.add(new ml.activation.ReLU());
        network.add(new ml.layer.DenseLayer(64, 10));
        network.add(new ml.activation.Softmax());

        Adam optimizer = new Adam(0.001);
        CrossEntropyLoss loss = new CrossEntropyLoss();
        Trainer trainer = new Trainer(network, loss, optimizer)
            .withGradientClipper(new ml.regularization.GradientClipper(5.0))
            .withWeightDecay(new ml.regularization.WeightDecay(0, 1e-4));

        System.out.println("Warming up...");
        trainer.fit(trainData.images(), trainData.labels(), 1, 256);

        System.out.println("\nBenchmarking 3 epochs...");
        long start = System.currentTimeMillis();
        trainer.fit(trainData.images(), trainData.labels(), 3, 256);
        long elapsed = System.currentTimeMillis() - start;
        System.out.printf("%nTotal: %dms for 3 epochs => %.0f ms/epoch%n", elapsed, elapsed / 3.0);
    }
}
