Part I — Foundations

1 · Philosophy & Architecture

What mnist-dl is, why it exists, and how it is organized.

Pure JavaNo Python, no JNI, no native libs. Java 17, Maven, JFreeChart for plotting.
Parallel by defaultTensor ops, matmul, reductions & DataLoader use ExecutorService + CompletableFuture.
Batteries included15 layers, 14 activations, 9 losses, 5 optimizers, 6 app domains with runnable projects.*.

Mental model

The library follows the classic deep learning stack: Tensor → Layer → NeuralNetwork → Loss + Optimizer + Trainer → Evaluator. Everything is composed via the Layer interface. Data flows as Tensor(rows=batch, cols=features) with row-major double arrays.

Tensor (batch × features) → [Dense → Activation → Dropout → ... → Softmax] → Loss → Optimizer.step() ↻ Trainer.fit()

2 · Tensor — The Foundation

File: ml/core/Tensor.java · Thread-safe, parallel, row-major double[] of shape [rows, cols].

Why a custom Tensor?

Java has no native ND-array. Tensor gives the whole library a single, cache-friendly, parallelized primitive without pulling in ND4J or PyTorch JNI.

Construction

Tensor a = new Tensor(32, 784);                 // zeros
Tensor b = Tensor.ones(4, 4);
Tensor c = Tensor.filled(2, 3, 0.5);
Tensor r = Tensor.random(8, 128);               // Uniform [0,1)
Tensor n = Tensor.randomNormal(8, 128);         // N(0,1)
Tensor x = Tensor.xavier(256, 128);             // Xavier/Glorot (scaled normal)
Tensor h = Tensor.he(256, 128);                 // He (good for ReLU)
Tensor t = new Tensor(new double[][]{{1,2},{3,4}});
Tensor f = Tensor.fromFlat(flatArray, 10, 784); // reshape

int[] shape = t.shape(); // [rows, cols]
double v = t.get(0, 3);
t.set(0, 3, 0.42);
double[] row = t.row(1);
Tensor slice = t.sliceRows(0, 64); // view copy of first 64 rows

Parallel execution model

Thresholds: element-wise PARALLEL_THRESHOLD=50_000, matmul MATMUL_PARALLEL_OPS=2_000_000. Above that, operations shard across ThreadPoolManager.compute() with CompletableFuture.

// Matmul is sharded by output rows
Tensor out = Tensor.matmul(a, b); // a[mxk] * b[kxn] = [mxn]
Tensor tr  = a.transpose();
Tensor sum = a.add(b);            // element-wise (also subtract/multiply/divide)
a.addInPlace(b);                  // in-place variant
Tensor scaled = a.multiply(0.5);
a.multiplyInPlace(0.5);

double s = a.sum();   // parallel reduction
double m = a.mean();
double mx = a.max(); double mn = a.min();
int best = a.argmaxRow(0);
int[] preds = a.argmaxAll();
Tensor rowSums = a.sumRows(); // [rows,1]
Tensor colSums = a.sumCols(); // [1,cols]
Tensor y = a.apply(x -> Math.max(0, x)); // parallel map
a.applyInPlace(Math::tanh);
Tensor clipped = a.clip(-1, 1);
Tensor copy = a.copy();
double[][] arr = a.toArray();
Shape discipline: The library uses 2-D tensors only. Images are flattened (e.g., 28×28 → 784), sequences are flattened as seqLen * features per row. Conv2D reconstructs H = sqrt(cols / channels) internally.

3 · The Layer Interface

File: ml/layer/Layer.java — every composable block implements this.

public interface Layer {
    Tensor forward(Tensor input, boolean training);
    Tensor backward(Tensor gradient);
    void   update(double learningRate);
    int    inputSize();
    int    outputSize();
    int    parameterCount();
    default Tensor forward(Tensor input){ return forward(input,false); }
}
  • forward(input, training) — training=true enables Dropout/BatchNorm training behaviour.
  • backward(gradient) — returns dL/dInput; stores dL/dW internally for update.
  • update(lr) — SGD step (optimizers call this or handle Dense specially).
  • inputSize/outputSize — return -1 for shape-agnostic layers (activations, pooling).

Base for activations: ActivationLayer caches lastInput/lastOutput and delegates to computeForward.

public abstract class ActivationLayer implements Layer {
    protected Tensor lastInput, lastOutput;
    public Tensor forward(Tensor input, boolean t){
        this.lastInput=input; this.lastOutput=computeForward(input); return lastOutput;
    }
    protected abstract Tensor computeForward(Tensor input);
    public int inputSize(){return -1;} public int outputSize(){return -1;}
    public int parameterCount(){return 0;} public void update(double lr){}
}

4 · Core Layers: Dense, Conv2D, Flatten, Embedding

DenseLayer — Fully Connected ml/layer/DenseLayer.java

Computes y = x·Wᵀ + b with He-initialized W[outputSize × inputSize]. Backward is parallel sharded; bias broadcasting and weight update are parallel.

DenseLayer fc1 = new DenseLayer(784, 256); // in=784, out=256
DenseLayer fc2 = new DenseLayer(256, 10);

NeuralNetwork net = new NeuralNetwork().add(fc1).add(new ReLU()).add(fc2);
Tensor out = net.forward(batch);          // [batch,10]
Tensor dInput = fc2.backward(grad);       // returns dL/dx
fc2.update(0.001);                        // SGD step

// Introspection
Tensor W = fc1.weights();   // [256,784]
Tensor b = fc1.bias();      // [1,256]
Tensor dW = fc1.weightsGradient();
System.out.println(net.totalParameters());

// Shape guard — throws LayerConfigurationException on mismatch
new NeuralNetwork().add(new DenseLayer(10,20)).add(new DenseLayer(30,5)); // ❌ throws
When to use: Tabular data, MLP heads, final classifier after Conv/Recurrent stacks. Parameter count = in×out + out.

Conv2D — 2D Convolution ml/layer/Conv2D.java

Square images assumed: H = sqrt(cols / inChannels). Supports stride, padding, multiple output channels. Kernels are Tensor[inChannels·k·k, 1] per output channel.

// Classic LeNet-style stem for 28×28 grayscale
Conv2D conv1 = new Conv2D(1, 16, 3);              // 1→16 channels, 3×3 kernel
Conv2D conv2 = new Conv2D(16, 32, 3, 1, 1, new Random(0)); // stride 1, pad 1

NeuralNetwork cnn = new NeuralNetwork()
  .add(new Conv2D(1, 16, 3))
  .add(new ReLU())
  .add(new MaxPool(2))          // 28→14
  .add(new Conv2D(16, 32, 3))
  .add(new ReLU())
  .add(new MaxPool(2))          // 14→7  (32*7*7 = 1568 features)
  .add(new Flatten())
  .add(new DenseLayer(1568, 128))
  .add(new ReLU())
  .add(new DenseLayer(128, 10))
  .add(new Softmax());

// Access kernels
Tensor k0 = conv1.kernel(0);
double[] bias = conv1.biases();
int params = conv1.parameterCount(); // outC*inC*k*k + outC

Flatten ml/layer/Flatten.java

Reshapes [batch, H·W·C] → [batch, H·W·C] (logically flattens spatial dims for Dense). No parameters, backward is identity reshape.

Flatten flat = new Flatten();
NeuralNetwork net2 = new NeuralNetwork().add(new Conv2D(1,8,3)).add(new Flatten()).add(new DenseLayer(-1,64));
// Note: Flatten reports inputSize/outputSize = -1 so NeuralNetwork skips shape check

Embedding ml/layer/Embedding.java

Lookup table [vocabSize × embeddingDim]. Input is expected to carry token ids (as doubles) — projects encode via Vocab + bag-of-words or id sequences.

Embedding emb = new Embedding(5000, 128); // vocab 5k, dim 128
Tensor ids = Tensor.fromFlat(new double[]{12, 45, 7, 0}, 1, 4);
Tensor embedded = emb.forward(ids, true); // [1, 4*128] — flattened sequence
System.out.println(emb.parameterCount()); // 5000*128
Tip: For NLP, combine Embedding → LSTMLayer → Dense → Softmax. See Projects P06–P11.

5 · Normalization: BatchNorm & LayerNorm

BatchNorm ml/layer/BatchNorm.java

Normalizes across batch: y = γ·(x-μ)/√(σ²+ε) + β. Tracks runningMean/runningVar for inference.

BatchNorm bn = new BatchNorm(128); // featureSize
NeuralNetwork net = new NeuralNetwork()
  .add(new DenseLayer(784,128))
  .add(new BatchNorm(128))
  .add(new ReLU())
  .add(new DenseLayer(128,10))
  .add(new Softmax());

Tensor trainOut = net.forward(batch, true);  // uses batch stats
Tensor testOut  = net.forward(batch, false); // uses running stats

// Trainable params
Tensor gamma = bn.gamma(); // [1,128]
Tensor beta  = bn.beta();

LayerNorm ml/layer/LayerNorm.java

Normalizes across features per sample (Transformer staple). No running stats; always uses per-row mean/var.

LayerNorm ln = new LayerNorm(512);
TransformerBlock block = new TransformerBlock(512, 8, 2048);

NeuralNetwork seq = new NeuralNetwork()
  .add(new DenseLayer(128,512))
  .add(new LayerNorm(512))
  .add(new TransformerBlock(512, 8, 2048))
  .add(new DenseLayer(512, 10));

// Inside TransformerBlock (preNorm=true by default):
// x → LayerNorm → MultiHeadAttention → Dropout → residual
//   → LayerNorm → FFN(ReLU) → Dropout → residual
LayerNormalizes overParamsBest for
BatchNormBatch dim2×features (γ,β)CNNs, MLPs with batch > 16
LayerNormFeature dim per sample2×features (γ,β)Transformers, RNNs, batch=1

6 · Pooling: MaxPool & AvgPool

Files: ml/layer/MaxPool.java, AvgPool.java · Parameter-free spatial downsampling.

MaxPool

MaxPool pool2 = new MaxPool(2);       // 2×2, stride 2
MaxPool pool3 = new MaxPool(3, 1);    // 3×3, stride 1
NeuralNetwork net = new NeuralNetwork()
  .add(new Conv2D(1,16,3))
  .add(new ReLU())
  .add(new MaxPool(2))  // 28×28 → 14×14
  .add(new Conv2D(16,32,3))
  .add(new MaxPool(2)); // 14×14 → 7×7 (approx, depends on valid conv)

Keeps strongest activation per window — best for feature selection, translation invariance.

AvgPool

AvgPool avg = new AvgPool(2);
NeuralNetwork net2 = new NeuralNetwork()
  .add(new Conv2D(1,16,3))
  .add(new AvgPool(2))
  .add(new Flatten());
// AvgPool backward distributes gradient uniformly (1/(k*k))

Averages window — smoother, often used before global pooling / classification head.

Both infer H = sqrt(cols) (or sqrt(cols/channels)) and compute outH = (H - pool)/stride + 1. Report inputSize/outputSize = -1 so shape checks are skipped.

7 · Recurrence: RNN, LSTM, GRU

Sequence layers consume Tensor[batch, seqLen*inputSize] flattened. They are the workhorses for time-series and NLP.

RNNLayer ml/layer/RNNLayer.java

Elman RNN with tanh/ReLU/sigmoid/ELU. Supports bidirectional and returnSequences.

RNNLayer rnn = new RNNLayer(1, 64); // input 1-dim, hidden 64
RNNLayer birnn = new RNNLayer(8, 32, true); // bidirectional
RNNLayer seqRnn = new RNNLayer(10, 32, false, true, "relu"); // returns all timesteps

Tensor seq = new Tensor(16, 20*10); // batch 16, seqLen 20, feat 10
Tensor lastHidden = rnn.forward(seq, true);      // [16,64]
Tensor allHidden  = seqRnn.forward(seq, true);   // [16,20*32]

LSTMLayer — True BPTT ml/layer/LSTMLayer.java

Full LSTM with forget/input/output gates + cell state and true backprop-through-time. Bidirectional concatenates forward+backward hiddens. ~4× params of RNN.

// Temperature forecasting: 24h lookback → next temp
LSTMLayer lstm = new LSTMLayer(1, 64);
NeuralNetwork forecaster = new NeuralNetwork()
  .add(new LSTMLayer(1, 64))          // [batch, 24*1] → [batch,64]
  .add(new DenseLayer(64, 32))
  .add(new ReLU())
  .add(new DenseLayer(32, 1));        // regression output

// Sequence-to-sequence (returnSequences=true) — stack them!
NeuralNetwork stacked = new NeuralNetwork()
  .add(new LSTMLayer(10, 64, false, true))  // → [batch, seqLen*64]
  .add(new LSTMLayer(64, 32))                // → [batch,32]
  .add(new DenseLayer(32, 5))
  .add(new Softmax());

// Bidirectional for NLP
LSTMLayer bilstm = new LSTMLayer(128, 64, true, false);
System.out.println(lstm.parameterCount()); // 4*(in*hid + hid*hid + hid)

GRULayer ml/layer/GRULayer.java

Gated Recurrent Unit — 3 gates (update, reset, candidate), lighter than LSTM, strong on small datasets.

GRULayer gru = new GRULayer(10, 64);
GRULayer bigru = new GRULayer(10, 32, true);
NeuralNetwork net = new NeuralNetwork()
  .add(new Embedding(1000, 32))
  .add(new GRULayer(32, 64))
  .add(new DenseLayer(64, 2))
  .add(new Softmax());

8 · Attention: SelfAttention → MultiHead → TransformerBlock

SelfAttention ml/layer/SelfAttention.java

Scaled dot-product attention: Q=XWQ, K=XWK, V=XWV, Attn=softmax(QKᵀ/√d), Out=Attn·V·WO.

SelfAttention attn = new SelfAttention(64); // embedDim 64
SelfAttention noScale = new SelfAttention(64, false);
Tensor out = attn.forward(seqTensor, true); // [batch, seqLen*64]
Tensor weights = attn.getAttentionWeights(); // inspect [seqLen × seqLen]

MultiHeadAttention ml/layer/MultiHeadAttention.java

Splits embedDim into numHeads heads (each headDim = embedDim/numHeads), runs attention per head, concatenates, projects via WO. Supports cross-attention.

MultiHeadAttention mha = new MultiHeadAttention(512, 8);
MultiHeadAttention cross = new MultiHeadAttention(512, 8, true);
Tensor query = new Tensor(4, 10*512); // batch 4, seqLen 10
Tensor kv    = new Tensor(4, 12*512); // encoder output
Tensor out2  = cross.forward(query, kv, true);

// Standard self-attention via Layer interface
NeuralNetwork withMHA = new NeuralNetwork()
  .add(new MultiHeadAttention(128, 4))
  .add(new LayerNorm(128));

TransformerBlock ml/layer/TransformerBlock.java

Full block: Norm → MHA → Dropout → Residual → Norm → FFN(ReLU) → Dropout → Residual. Toggle preNorm for Pre-LN vs Post-LN.

TransformerBlock block = new TransformerBlock(512, 8, 2048); // embed, heads, ffDim
TransformerBlock crossBlock = new TransformerBlock(512, 8, 2048, true, true, 0.1);
TransformerBlock light = new TransformerBlock(128, 4, 512, false, true, 0.1);

NeuralNetwork transformer = new NeuralNetwork()
  .add(new DenseLayer(64, 512))
  .add(new TransformerBlock(512, 8, 2048))
  .add(new TransformerBlock(512, 8, 2048))
  .add(new LayerNorm(512))
  .add(new DenseLayer(512, 1000))
  .add(new Softmax());

// Encoder-decoder cross-attention
Tensor encOut = transformer.forward(src, true); // placeholder
Tensor decOut = crossBlock.forward(tgt, encOut, true);
When to use what: SelfAttention for single-sequence tasks · MultiHead for richer representation · TransformerBlock for any modern NLP/vision transformer. Stack 2–6 blocks; always follow with LayerNorm.

9 · Regularization & Augmentation

Dropout ml/regularization/Dropout.java

Dropout drop = new Dropout(0.3); // 30% drop
Dropout mild = new Dropout(0.1);
NeuralNetwork net = new NeuralNetwork()
  .add(new DenseLayer(784,256))
  .add(new ReLU())
  .add(new Dropout(0.2))   // training=true → mask & scale 1/(1-p)
  .add(new DenseLayer(256,10))
  .add(new Softmax());

Tensor trainOut = net.forward(x, true);  // dropout active
Tensor testOut  = net.forward(x, false); // passthrough
// In backward(), gradient is masked identically

WeightDecay ml/regularization/WeightDecay.java

WeightDecay l2 = new WeightDecay(0, 1e-4); // L2 only
WeightDecay l1l2 = new WeightDecay(1e-5, 1e-4);
Trainer t = new Trainer(net, loss, opt)
  .withWeightDecay(l2);
// Applied after optimizer step: W -= lr*(l1*sign(W)+l2*W)
double penalty = l2.computeLoss(net.getLayers());

GradientClipper ml/regularization/GradientClipper.java

GradientClipper byNorm  = new GradientClipper(5.0); // clip by global norm
GradientClipper byValue = new GradientClipper(
  GradientClipper.Mode.VALUE, 1.0); // clip each grad to [-1,1]

Trainer t2 = new Trainer(net, loss, opt)
  .withGradientClipper(byNorm)
  .withWeightDecay(new WeightDecay(1e-4));
// Trainer calls clipper.clip(layers) before optimizer.step()

Data Augmentation (all are Layer)

Operate on flattened images; auto-detect H = sqrt(cols). Only active when training=true.

RandomFlip flipH = new RandomFlip("horizontal", 0.5);
RandomFlip flipV = new RandomFlip("vertical", 0.5);
RandomFlip flipBoth = new RandomFlip("both", 0.5);

RandomRotation rot = new RandomRotation(15.0, 0.5); // ±15°
RandomCrop crop = new RandomCrop(24, 0.5);         // crop 24×24 from 28×28
RandomZoom zoom = new RandomZoom(0.2, 0.5);        // zoom ±20%

NeuralNetwork augNet = new NeuralNetwork()
  .add(new RandomFlip("horizontal", 0.5))
  .add(new RandomRotation(10.0, 0.3))
  .add(new DenseLayer(784,256))
  .add(new ReLU())
  .add(new DenseLayer(256,10))
  .add(new Softmax());

Tensor augmented = augNet.forward(batch, true);
Tensor clean     = augNet.forward(batch, false); // no augmentation
Ordering matters: Place augmentation layers first (before Dense/Conv) so they transform raw inputs, not features.

11 · Loss Functions — 9 Ways to Be Wrong

Interface: ml/loss/Loss.java — forward(predictions, labels) → double + backward → Tensor.

// 1. CrossEntropy — multi-class classification (with Softmax)
CrossEntropyLoss ce = new CrossEntropyLoss(); // eps 1e-12
double loss = ce.forward(probs, labels);      // -mean(log p_true)
Tensor grad = ce.backward(probs, labels);     // (p - oneHot)/batch

// 2. BinaryCrossEntropy — binary / multi-label
BinaryCrossEntropyLoss bce = new BinaryCrossEntropyLoss();
double l2 = bce.forward(probs, labels);
Tensor g2 = bce.backward(probs, targets); // also Tensor overload
// Tensor overload: bce.forward(pred, targetTensor)

// 3. MSELoss — regression, autoencoder
MSELoss mse = new MSELoss();
double l3 = mse.forward(pred, labels);      // int[] labels → one-hot
double l3b= mse.forward(pred, targetTensor); // direct tensor
Tensor g3 = mse.backward(pred, targetTensor); // 2*(pred-target)/batch

// 4. HuberLoss — robust regression (quadratic near 0, linear far)
HuberLoss huber = new HuberLoss(1.0); // delta
double l4 = huber.forward(pred, labels);

// 5. HingeLoss — SVM / max-margin
HingeLoss hinge = new HingeLoss();
// loss = mean(max(0, s_wrong - s_true + 1))

// 6. FocalLoss — addresses class imbalance (RetinaNet)
FocalLoss focal = new FocalLoss(0.25, 2.0); // alpha, gamma
FocalLoss focal2 = new FocalLoss();         // defaults 0.25, 2.0

// 7. KLDivergenceLoss — distillation, VAE
KLDivergenceLoss kl = new KLDivergenceLoss();
double l7 = kl.forward(pred, labels);

// 8. CosineEmbeddingLoss — similarity learning, retrieval
CosineEmbeddingLoss cos = new CosineEmbeddingLoss();
double l8 = cos.forward(pred, labels);

// 9. CTCLoss — speech/handwriting (blank-aware, zeroInfinity)
CTCLoss ctc = new CTCLoss(0, true); // blank=0
double l9 = ctc.forward(logProbs, labels);
Tensor g9 = ctc.backward(logProbs, labels);

// All losses share Trainer wiring:
Trainer t = new Trainer(net, new CrossEntropyLoss(), new Adam(0.001));
Trainer t2= new Trainer(net, new MSELoss(), new SGD(0.01));
Trainer t3= new Trainer(net, new FocalLoss(0.25,2.0), new AdamW(0.001));
Trainer t4= new Trainer(net, new HuberLoss(0.5), new Adam(0.002));

12 · Optimizers — 5 Update Rules

Interface: ml/optimizer/Optimizer.java — step(layers, learningRate). Dense layers get specialized parallel updates; other layers delegate to layer.update(lr).

// SGD — vanilla + optional momentum
SGD sgd = new SGD(0.01);              // no momentum
SGD sgdM = new SGD(0.01, 0.9);        // momentum 0.9
// update: v = μv + lr·g ;  W -= v   (or W -= lr·g if μ=0)

// Adam — adaptive moments (default choice)
Adam adam = new Adam(0.001);          // beta1 0.9, beta2 0.999, eps 1e-8
Adam adam2= new Adam(0.001, 0.9, 0.999, 1e-8);
// m = β1·m + (1-β1)g ; v = β2·v + (1-β2)g² ;  W -= lr·m̂/(√v̂+ε)

// AdamW — Adam with decoupled weight decay (best for transformers)
AdamW adamW = new AdamW(0.001, 0.01); // lr, weightDecay
AdamW adamW2= new AdamW(0.001, 0.9, 0.999, 1e-8, 0.01);

// RMSProp — moving average of squared grads
RMSProp rms = new RMSProp(0.001);            // decay 0.9
RMSProp rms2= new RMSProp(0.001, 0.9, 1e-8);
// cache = ρ·cache + (1-ρ)g² ;  W -= lr·g/(√cache+ε)

// AdaGrad — accumulates all past squared grads (good for sparse)
AdaGrad ada = new AdaGrad(0.01);
AdaGrad ada2= new AdaGrad(0.01, 1e-8);
// cache += g² ;  W -= lr·g/(√cache+ε)

// Wiring with Trainer — lr can be overridden per fit
Trainer t = new Trainer(net, loss, new Adam(0.001));
t.setLearningRate(0.0005); // propagates to optimizer

// Save / resume optimizer state (momentum buffers etc.)

Choosing components — decision tree

Task = classify images?       → Conv2D + MaxPool + Dense + CrossEntropy + Adam + Softmax
Task = classify text?         → Embedding/Vocab + LSTM or TransformerBlock + CrossEntropy + AdamW
Task = tabular (few cols)?    → Dense(4-64) + ReLU + Dropout + CrossEntropy/MSE + Adam
Task = forecast next value?   → LSTMLayer/GRULayer (returnSequences?) + Dense + MSELoss + Adam
Task = detect anomaly?        → Dense Autoencoder 784→64→784 + MSELoss (threshold on recon error)
Task = imbalanced binary?     → Dense + Sigmoid + FocalLoss (or BCE + class weights via sampling)
Task = sequence alignment?    → LSTM + CTCLoss (blank token)
Need sparse / large vocab?    → AdaGrad or Adam + Embedding + FocalLoss
Need best generalization?     → AdamW + WeightDecay + GradientClipper + Cosine/Warmup scheduler + EarlyStopping

Common pitfalls

  • Shape mismatch: NeuralNetwork.add checks prev.outputSize == next.inputSize for Dense/BN/LN. Pool/Activation/Flatten skip checks (-1). Conv2D infers H — ensure cols is a perfect square × channels.
  • Forgetting training=true: Dropout and augmentation are no-ops when false. Always pass true in the training loop (Trainer does).
  • Loss/activation mismatch: CrossEntropy expects Softmax probs; BCE expects Sigmoid; MSE expects linear. Mismatch gives NaN or plateau.
  • Learning rate too high: Start 0.001 for Adam, 0.01 for SGD. Use GradientClipper(5.0) to avoid explosions in RNNs.
  • Not shuffling: DataLoader shuffles by default — keep it for training, disable for deterministic eval.
