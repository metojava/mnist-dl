21 · ML Patterns — Formulas, When-to-Use & Charts

Seven patterns that cover 90% of what you will build with mnist-dl. Each has formula, diagram, code skeleton, and which library pieces to pick.

1 · MLP — Universal approximator

y = Softmax( W3·ReLU( W2·ReLU(W1x + b1) + b2) + b3 )
He init + ReLU avoids vanishing; Dropout 0.2 prevents co-adaptation. 
new NeuralNetwork()
 .add(new DenseLayer(784,256)).add(new ReLU()).add(new Dropout(0.2))
 .add(new DenseLayer(256,128)).add(new ReLU())
 .add(new DenseLayer(128,10)).add(new Softmax()); // + CrossEntropy + Adam

Use: Tabular, Fashion-MNIST baseline, MLP head after CNN/RNN.

2 · CNN — Locality + translation invariance

( f ∗ k )(i,j) = Σm,n f(i+m−n)·k(m,n)   + bias , then ReLU → MaxPool
Library infers H=√(cols/channels); kernel 3→ valid conv shrinks H by 2. 
new NeuralNetwork().add(new Conv2D(1,16,3)).add(new ReLU()).add(new MaxPool(2))
 .add(new Conv2D(16,32,3)).add(new ReLU()).add(new MaxPool(2))
 .add(new Flatten()).add(new DenseLayer(1568,10)).add(new Softmax());

3 · Autoencoder — Unsupervised compression

ℒ = MSE( x, Dec( Enc( Noisy(x) ) ) )   , bottleneck dim << input
Denoising: add 15% salt-pepper → learn to clean. 
new NeuralNetwork()
 .add(new DenseLayer(784,256)).add(new ReLU())
 .add(new DenseLayer(256,64)).add(new ReLU()) // bottleneck
 .add(new DenseLayer(64,256)).add(new ReLU())
 .add(new DenseLayer(256,784)).add(new Sigmoid()); // + MSELoss

4 · RNN/LSTM — Sequences

ht = tanh( Wxxt + Whht-1 + b )
LSTM: i,f,o,g gates → ct=f⊙ct-1+i⊙g , ht=o⊙tanh(ct)
t →LSTM → ht →LSTM → ht+1

5 · Attention/Transformer — Long-range

Attention = softmax(QKT/√d)·V   MultiHead = Concat(heads)·WO
Block = x + MHA(LN(x)) → y = x₁ + FFN(LN(x₁))

See 19 · Transformers for full diagrams.

6 · Imbalanced — Focal & threshold

Focal: −α(1−pt)γ log(pt)   γ=2 focuses on hard positives
Sweep threshold 0.05→0.95 to maximize F1; report TP/FP/FN. 
new Trainer(net, new FocalLoss(0.25,2.0), new Adam(0.003)).fit(...);
// sweep: for(thr) compute p=TP/(TP+FP), r=TP/(TP+FN), F1=2pr/(p+r)

7 · Transfer / Ensemble

  • Ensemble (P05): bootstrap 3×, train 3 nets, majority vote — reduces variance.
  • Conceptual transfer: train AE bottleneck 64, then reuse encoder as feature extractor for classifier.
Start with one pattern, get it to 90% of target metric, then switch pattern — don’t mix all at once. This library lets you swap a single add(...) line to test a new pattern.
